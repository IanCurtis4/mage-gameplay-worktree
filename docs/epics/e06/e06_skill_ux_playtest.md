# E06 — janela de habilidades

Pare a execução antiga e use F5 no projeto habitual. Abra a aba Skills no lobby: habilidades à esquerda, detalhes e24 atalhos à direita. A identidade/classificação dos ícones também aparece na barra do mapa.

1. Alterne Árvore / Lista. Abra as abas de job: habilidades bloqueadas permanecem visíveis, com requisitos e custos reais. Azul permite aumentar; vermelho já tem rank; cinza exige algum requisito. O + de uma skill vermelha continua disponível quando pode receber outro ponto.
2. Clique ou passe o mouse numa skill para ver sua descrição, ranks, SP/recarga, requisitos e caminho seguinte. Passivas delineadas funcionam automaticamente; ativas devem ser colocadas nos atalhos.
3. Use + para preparar pontos; veja a carteira e o marcador de pendência. − remove somente aumentos pendentes que não invalidem dependências. Desfazer pendências não devolve compras antigas. ✓ Aplicar confirma o lote numa gravação única.
4. Organize os atalhos pela biblioteca/arraste ou selecione um slot e atribua uma skill confirmada. Alterar tecla captura combinações; conflitos/reservas continuam validados. Os24 slots existentes são preservados, com rolagem para alcançar o restante da janela.
5. Feche a janela pelo × e reabra a aba Skills. Pendências descartadas, compras preservadas. Trocar personagem, preset/revisão ou evolução também invalida o rascunho.
6. No mapa, abra Habilidades. A run pausa para consulta; compras continuam no lobby. Skills concedidas por itens aparecem identificadas e mantêm as regras de acesso existentes. Feche pelo × ou Esc para retomar. Treino e sessão local permitem consulta sem alterar o perfil.

O modo árvore organiza verticalmente os pré-requisitos publicados. Onde as regras usam apenas nível de Job, mostra esse gate; não foram inventadas conexões, novas quests, classes, custos ou slots. Detalhes mostram valores base do catálogo; a barra de combate continua mostrando o estado efetivo da skill. Os novos SVGs são arte original; fontes e equipamentos anteriores foram preservados.
